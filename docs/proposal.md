Project Selection
We propose developing a relational database for a gym to organize memberships, payments, scheduled fitness classes, trainer assignments, and member attendance. The database will support routine record keeping and answer five management questions about revenue, retention, class demand, attendance, and trainer workload.
A gym needs to know which members hold valid memberships, when those memberships expire, which payments have been received, and whether classes are using available capacity effectively. Maintaining these records in disconnected spreadsheets can produce inconsistent member information, duplicate reservations, and incomplete reports. Our project will connect these records through a common database so that managers can retrieve reliable information without repeatedly entering the same facts.
The proposed database will include members, membership plans, individual membership periods, membership payments, trainers, class types, scheduled class sessions, and enrollments. Each membership will belong to one member and one plan. Each payment will be associated with the membership it pays for. Each session will identify a class type, trainer, date, time, and capacity. Enrollments will connect members to sessions and record booking and attendance status. A member may have multiple membership periods and attend multiple sessions over time.
We will use MySQL to implement the database to manage tables and queries. We will prepare an entity relationship diagram, a data dictionary, and a design normalized through third normal form. Primary keys, foreign keys, uniqueness rules, and validation constraints will support data consistency. Business rules will prohibit duplicate bookings for the same member and session, require positive session capacities, and distinguish booked, canceled, attended, and missed reservations. Capacity and active-membership checks will be documented and enforced through an appropriate implementation method selected during development.
The scope is one gym location with group fitness classes and membership payments. A customer website, mobile application, payroll system, equipment inventory, and payment processing integration are outside the proposed scope. We will use fictional sample data with several months of memberships, payments, and class activity. These records will include renewals, expired memberships, cancellations, and no-shows so that the analytical questions can be demonstrated without using real member information.
Analytical Scope
Our project will answer the following five questions. The measures will use a specified reporting period so that results can be reproduced and compared consistently.
Question 1: How much membership payment revenue does the gym receive each month, and which membership plans contribute the most? We will sum completed membership payments by payment month and plan. Revenue here means money received, rather than accounting revenue recognized over the membership period; pending, failed, and refunded payments will be excluded from this measure.
Question 2: What percentage of expiring memberships renew within 30 days after expiration, and how does this rate vary by plan? We will identify membership periods ending in the reporting period and determine whether the same member starts a subsequent membership within the defined renewal window. We will report only expiration with a complete 30-day follow-up period and count each expiring membership once.
Question 3: Which class types and time slots have the highest booking utilization? For each completed session, we will compare non-canceled reservations with session capacity, then summarize the results by class type and time slot. We will distinguish the number of bookings from the percentage of available spaces booked so that larger classes do not automatically appear more popular.
Question 4: Which class types and time slots have the highest attendance and no-show rates? We will use completed sessions with finalized attendance records. Attendance rate will be attended reservations divided by attended plus missed reservations; no-show rate will use missed reservations over the same denominator. Canceled reservations will be excluded, and sessions with no eligible reservations will have an undefined rate rather than a misleading zero.
Question 5: How is teaching workload distributed among trainers during the reporting period? We will compare the number of completed sessions and total scheduled teaching hours for each trainer. We will include trainers with no completed sessions and describe workload differences without treating those differences alone as evidence of trainer performance.
